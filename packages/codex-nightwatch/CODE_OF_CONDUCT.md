# Code of Conduct

This project should remain a practical, respectful engineering space.

Expected behavior:

- Be direct and constructive.
- Focus criticism on code, docs, tests, and design tradeoffs.
- Assume public artifacts may be read by users with different experience levels.
- Do not include secrets, private logs, or personal data in issues, fixtures, or examples.

Unacceptable behavior:

- Harassment, threats, or targeted personal attacks.
- Publishing private credentials, local transcripts, or sensitive account details.
- Misrepresenting the project as an official OpenAI product.

Before public release, replace this lightweight policy with the maintainers' preferred formal code of conduct if needed.
