# Code of Conduct

## Our commitment
This project is committed to a friendly, safe, and welcoming environment for everyone — regardless of
experience level, background, or identity. Contributing here should be a harassment-free experience.

## Our standards
Behavior that helps the community: being respectful, patient, and welcoming; giving and gracefully
accepting constructive feedback; focusing on what's best for the project and its users.

Unacceptable behavior includes harassment of any kind, personal or political attacks, publishing
others' private information without permission, and conduct a reasonable person would consider
inappropriate in a professional setting.

## Scope
Applies in all project spaces (issues, pull requests, discussions, commits) and when representing the
project in public.

## Reporting and enforcement
Report unacceptable behavior privately to the maintainer — preferred: open a **confidential
issue** (tick "This issue is confidential" so only project members can see it); or contact the
repository owner directly. Reports are handled confidentially. The maintainer may take any
action deemed appropriate, up to a temporary or permanent ban. For serious abuse, use GitLab's
[report abuse](https://gitlab.com/-/abuse_reports/add) flow.
